# Code of conduct

This project is a place to work on research software together. To keep it useful for everyone:

- Be respectful. Disagree about the work, not about the person.
- Assume good faith, and say plainly what you need and what you have verified.
- No harassment, discrimination, personal attacks, threats, or publishing someone else's private information.
- No spam, advertising, or requests for investment, trading or account details.
- Keep issues and reviews on topic and specific.

## Enforcement

The maintainer may edit, hide or delete comments, close or lock issues and pull requests, and restrict or remove access when conduct breaks these rules. Report a problem privately to the maintainer. The route is a GitHub private channel the maintainer must name here before this file is merged (not yet chosen, so none is invented). Reports are handled in confidence as far as that is possible.

There is a single maintainer today; if a report concerns the maintainer, say so, and ask a repository administrator or GitHub Support to review it. A second reviewer will be named here when one exists.

This is a short original statement and not the text of a particular published code.
